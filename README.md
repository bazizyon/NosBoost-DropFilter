# Drop Filter

A NosBoost mod that hides items on the ground that you don't care about.

## What it does

- Blacklist mode hides the items on your list. Whitelist mode hides everything else.
- Pick items from a searchable list with icons.
- Save as many lists as you want and switch between them.
- Hidden items stay hidden until you change map.

Lists are saved in `mods\DropFilter\`.

## Install

Download the DLL from this repo's Releases and put it in the game's `mods` folder. NosBoost loads it by itself. Open it from the NosBoost mods menu (F9).
